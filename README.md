## 如何部署到 GitHub Pages

1. 在 GitHub 创建仓库（如 `physics-to-cinema`）
2. 将所有 `.html` 文件上传到仓库根目录
3. 进入仓库 **Settings → Pages**
4. Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
5. 保存后等待几分钟，即可通过 `https://你的用户名.github.io/physics-to-cinema/` 访问
